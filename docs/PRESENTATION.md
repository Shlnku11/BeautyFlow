# Презентация BeautyFlow

Интерактивный слайд-дек для защиты проекта: [открыть презентацию](presentation/index.html).

После публикации на Vercel презентация будет доступна по адресу https://beautyflowy.vercel.app/presentation/.

Текст выступления, разбитый по номерам слайдов: [открыть speech.txt](presentation/speech.txt).

## Управление

- Стрелки влево/вправо или пробел — предыдущий/следующий слайд.
- Home и End — первый и последний слайд.
- T — переключить светлую и тёмную темы.
- При открытии презентация использует светлую или тёмную цветовую схему браузера и обновляется вместе с ней. Тему также можно переключить вручную клавишей T или кнопкой в шапке.
- F — полноэкранный режим.
- Кнопки внизу экрана и касание/свайп также работают.

Исходные стили, скрипт и скриншоты хранятся в папках проекта. Команда сборки Vercel собирает автономную копию презентации вместе с актуальными светлыми и тёмными скриншотами. При публикации на GitHub Pages загрузите папку презентации и `docs/screenshots/redesign/after`, сохраняя структуру каталогов. Кнопка «Открыть приложение» ведёт на https://beautyflowy.vercel.app.

Чтобы подготовить PDF-версию, запустите npm run presentation:pdf.
