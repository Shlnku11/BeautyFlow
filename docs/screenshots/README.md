# Скриншоты интерфейса

Актуальные пары `*-light.png` / `*-dark.png` генерируются Playwright из работающего Chromium после E2E-регистрации и настройки экранов. Все снимки сделаны при viewport `1440×1000` и включают полную высоту страницы. E2E использует временную тестовую replica set с применёнными миграциями; файлы показывают реальные экраны и ответы API с данными тестового бизнеса, не подменённые UI-моки.

| Экран | Файлы |
|---|---|
| Лендинг, вход, регистрация | `landing-*`, `login-*`, `register-*` |
| Обзор, календарь, записи | `dashboard-*`, `calendar-*`, `appointments-*` |
| Команда и услуги | `staff-*`, `staff-detail-*`, `services-*` |
| Клиенты | `customers-*`, `customer-detail-*` |
| Оплаты и настройки | `payments-*`, `settings-*` |
| День мастера | `my-day-*` |
| Публичная запись | `public-booking-*`, `public-confirmation-*`, `public-manage-*` |

`historical-dashboard-clay-*` — архив прежнего направления дизайна. Не использовать их как актуальный эталон.
