# Скриншоты интерфейса

Текущие снимки публичных страниц сделаны в Chromium при ширине viewport `1440px`; тема задавалась через `prefers-color-scheme`. Лендинг и вход сохранены в viewport `1440×900`, регистрация — на всю высоту страницы.

| Экран | Светлая тема | Тёмная тема |
|---|---|---|
| Лендинг | `landing-light.png` | `landing-dark.png` |
| Вход | `login-light.png` | `login-dark.png` |
| Регистрация бизнеса | `register-light.png` | `register-dark.png` |

Dashboard и другие экраны приложения требуют активной сессии и доступной MongoDB. На момент снимков API не отвечал в течение 5 секунд при запросе сессии, а Docker Engine с существующей MongoDB не был доступен. Поэтому закрытые страницы не заменялись моками. Файлы `historical-dashboard-clay-*` оставлены только как архив старого визуального направления.
